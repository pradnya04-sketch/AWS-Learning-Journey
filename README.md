
# AWS Learning Journey ☁️

Welcome to my hands-on AWS learning journey.

This repository documents my progress while preparing for the **AWS Certified Cloud Practitioner (CLF-C02)** certification and building practical knowledge of AWS Cloud services.

## 🎯 Goal

My goal is to understand AWS Cloud concepts through a combination of:

- 📚 Learning AWS concepts
- 💻 Hands-on practice
- 🛠️ Building small AWS projects
- 📝 Documenting what I learn
- 🔍 Troubleshooting real-world problems

I want to focus not only on understanding AWS for the certification, but also on developing practical cloud skills that I can apply in real projects.

## ☁️ Topics Covered

As I progress, this repository will include hands-on work and notes related to:

- Cloud Concepts
- IAM
- EC2
- S3
- EBS & EFS
- VPC & Networking
- RDS
- Lambda
- CloudFormation
- Monitoring & Management
- Security
- Billing & Pricing
- And other AWS services

## 🛠️ Hands-On Approach

For each major AWS service, I aim to document:

1. What the service is
2. Why it is used
3. Important concepts
4. Hands-on activities
5. Configurations and commands
6. Problems and troubleshooting
7. Key takeaways
8. Relevant CLF-C02 concepts
